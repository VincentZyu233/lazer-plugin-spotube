# Spotube (Spotify 曲库扩展)

基于 Spotube 经典架构打造的 Spotify 全球曲库插件：免登录畅享 Spotify 官方歌单与算法推荐，智能调度高保真无加密音频流。

## 🌟 核心特性
- **免登录即开即用**：全量走公开访客通道，无需配置账号或 API Key；
- **全域曲库与歌单秒开**：支持常规搜索，更支持直接在搜索栏粘贴任意 Spotify 歌单链接一键载入整张列表；
- **Spotube 官方置信度打分**：时长容差判定与官方纯音频频道加权，消除翻唱与片头杂音；
- **高保真流**：提供 128kbps AAC / Opus 裸音频流，纯 Lua 极致轻量；
- **同步歌词**：支持毫秒级同步逐行歌词与沉浸式高亮跟随。
