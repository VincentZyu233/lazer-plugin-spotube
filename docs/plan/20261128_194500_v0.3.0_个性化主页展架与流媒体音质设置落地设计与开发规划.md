## 1. 目标与背景

在 `v0.2.0` 版本中，`lazer-plugin-spotube` 成功打通了基础听歌与个人资产链路：
- 个人云端收藏与创建的歌单即时同步 (`userPlaylists`)；
- 艺人主页全生态链路（热门歌曲、专辑与单曲全收录）；
- L1/L2 双层缓存与 VideoID 永久记忆，实现了已播歌曲切歌 0 延迟秒开。

进入到 `v0.3.0`，我们聚焦于**主页视觉质感跃升**与**流媒体音质透明可控**，直击当前版本的两大核心痛点：
1. **主页千人一面、缺乏个性化**：当前 Lazer 主页仅展示静态的官方公共榜单（全球/美区/日区 Top 50），无法体现 Spotify 官方强大的“千人千面”算法推荐；而用户在 Spotify 网页端/客户端实际拥有极高质感的“每日混音 (Daily Mix)”、“每周新发现 (Discover Weekly)”、“艺人专属电台 (Artist Radio)”以及由 Spotify 服务端生成的拼贴封面（如周杰伦、Porter Robinson 电台等）。
2. **音频码率不可调、缺乏透明度**：目前音频流解析固定优先选择 `itag 251` (Opus ~160kbps)，在弱网或省流环境下用户无法自主降级为标准码率 AAC (128kbps) 或省流 Opus (70kbps)。

因此，**`v0.3.0` 的核心使命即是集中落地两项关键能力**：
- **P2.1 全局流媒体音质设置项 (`host.add_setting` 结合 `stream.lua` 自适应挑选)**
- **P2.2 登录用户个性化主页动态展架与服务端拼贴封面捕获 (`homeFeed` 算法升级)**

## 2. 协议依据与参考设计

### 2.1 Spotube 官方架构依据
在 `Spotube` 官方代码库（`team-spotube/spotube`）中：
- 模块 `org.spotube.plugin_interfaces.plugin_apis.audio` 定义了清晰的码率阶梯：
  - `High`: Opus ~160kbps (YouTube itag 251)
  - `Standard`: AAC ~128kbps (YouTube itag 140)
  - `Low`: Opus ~70kbps / 50kbps (YouTube itag 250 / 249)
- 用户可在客户端设置中选择 `preferredQuality`，流媒体解析器以此调整格式权重。

### 2.2 SpotAPI 协议依据
在 `SpotAPI`（`spotapi/operations.py`）中：
- Spotify 官方原生通过 Pathfinder 接口下发主页视图：
  - 操作名称：`home` 与 `homeSection`
  - 核心返回结构包含：
    - `title`: 国际化分组标题（如 `根据 VincentZyu 的喜好推荐`、`推荐电台`、`艺人热门歌曲`）
    - `items`: 包含电台与推荐歌单的 URI、名称、详细描述
    - `images`: **Spotify 服务端渲染的拼贴封面 URL**（`i.scdn.co/image/...` 或 `mosaic.scdn.co/...`），内置了艺人头像拼贴、专属色彩背景与设计排版。

## 3. 详细功能契约与架构设计

### 3.1 P2.1 全局流媒体音质设置项 (`host.add_setting`)

#### 契约规范与注册
利用 Lazer 原生提供的 `host.add_setting` API，在插件初始化时注册数据驱动的单选控件：
```lua
if host and type(host.add_setting) == "function" then
  pcall(host.add_setting, {
    id = "audio_quality",
    type = "select",
    title = "音频流质量与偏好",
    subtitle = "控制从音频源提取直链时的默认编码偏好",
    default = "high",
    options = {
      { value = "high", label = "高保真音质 (Opus ~160kbps)" },
      { value = "standard", label = "标准音质 (AAC ~128kbps)" },
      { value = "low", label = "流畅/省流模式 (Opus ~70kbps)" }
    }
  })
end
```

#### 调度逻辑 (`spotube/services/stream.lua`)
在 `extract_player_stream(video_id)` 提取音频自适应格式时：
1. 读取用户当前选定的 `audio_quality`：
   ```lua
   local quality = (store and store.get("setting:audio_quality")) or "high"
   ```
2. 依据偏好调整挑选权重：
   - 若 `quality == "high"`：优先 `itag_map[251]` (Opus 160k) -> `itag_map[140]` -> `itag_map[250]`
   - 若 `quality == "standard"`：优先 `itag_map[140]` (AAC 128k) -> `itag_map[251]` -> `itag_map[139]`
   - 若 `quality == "low"`：优先 `itag_map[250]` (Opus 70k) -> `itag_map[249]` -> `itag_map[139]`
3. 切换音质后主动使当前歌曲的流缓存失效，下次起播即按新码率加载。

### 3.2 P2.2 个性化主页动态展架 (`homeFeed`)

#### 契约规范
- **Capability 标识**：`"homeFeed"`（保持已有声明）
- **调用入口**：`plugin.call("homeFeed", args)`
- **返回契约结构**（严格对齐 Lazer 客户端标准）：
  ```lua
  {
    recommended = {
      -- 用户的个性化专属电台与每周新发现
      {
        id = "spotify:playlist:37i9dQZF1E4vT8i1v1",
        name = "周杰伦 电台",
        title = "周杰伦 电台",
        subtitle = "包含 王力宏, 陈奕迅, 孙燕姿 等艺人的作品",
        description = "包含 王力宏, 陈奕迅, 孙燕姿 等艺人的作品",
        coverUrl = "https://pickasso.spotifycdn.com/image/ab67c0de...",
        songCount = 50,
        provider = "spotube"
      },
      -- ...
    },
    editorialPlaylists = {
      -- 每周新发现 / 官方 This Is 系列作品
      {
        id = "spotify:playlist:37i9dQZF1DXcBWIGoYBM5M",
        name = "每周新发现",
        title = "每周新发现",
        subtitle = "精选小众宝藏音乐、冷门佳作和未来金曲",
        coverUrl = "https://newjams-images.scdn.co/image/ab6764...",
        songCount = 30,
        provider = "spotube"
      }
    },
    charts = {
      -- 全球热门榜单（降级兜底保留）
      {
        id = "37i9dQZEVXbMDoHDwVN2tF",
        name = "Top 50 - Global",
        title = "Top 50 - Global",
        coverUrl = "https://charts-images.scdn.co/REGULAR/overview-global.jpg",
        provider = "spotube"
      }
    }
  }
  ```

#### 数据拉取与双轨分流 (`spotube/services/spotify.lua`)
1. **状态判定**：检查本地存储的 `sp_dc` 与 `access_token`。
2. **已登录分支**：
   - 通过 Spotify Partner Pathfinder 查询 `home` 操作；
   - 提取各 Sections 中包含的卡片；
   - 解析出官方服务端生成的**拼贴封面（Cover Art）**与**艺人推荐描述**；
   - 组装为 `recommended` 与 `editorialPlaylists` 返回。
3. **未登录或网络异常分支**：
   - 自动且无感地平滑回退至现有的全球 Top 50 官方榜单，确保主页永不白屏。

### 5.2 Lazer 客户端实机验收用例

#### 步骤 0：前置环境确认
1. 启动或重启 Lazer 客户端；
2. 进入“设置 -> 扩展/插件”，确认 **Spotube** 插件版本显示为 **`0.3.0`**，且已启用；
3. 确保 Spotify 处于登录状态（持有有效 `sp_dc`）。

#### 用例 1：流媒体音质偏好配置验收 (P2.1)
- **测试路径**：
  1. 打开 Lazer **设置 -> 扩展/插件 -> Spotube**；
  2. 找到新增的配置项 **“音频流质量与偏好”**。
- **预期结果**：
  - 下拉框中显示 `高保真音质 (Opus ~160kbps)`、`标准音质 (AAC ~128kbps)` 与 `流畅/省流模式`；
  - 切换选项（例如从高保真切为标准音质），设置项即时持久化；
  - 播放一首新歌曲，查看音频属性/日志输出，确认音频流编码与所选偏好一致。

#### 用例 2：主页个性化展架与拼贴封面渲染验收 (P2.2)
- **测试路径**：点击 Lazer 顶部或侧边栏导航进入 **“首页 / 发现”**。
- **预期结果**：
  - **千人千面个性化展架**：主页不再只有单调的静态 Top 50，而是动态呈现专属电台（如根据用户喜好生成的 `周杰伦 电台`、`Porter Robinson 电台`、`This Is 系列`、`每周新发现` 等）；
  - **专属拼贴封面**：卡片封面直接显示 Spotify 官方渲染的高质感拼贴艺术图（带艺人专属色块、圆形头像排版与精致字体）；
  - **点击即播**：点击任意电台或推荐歌单，可顺利进入歌单详情页并展开歌曲列表，支持点播。

#### 用例 3：未登录状态下的安全回退
- **测试路径**：在插件中退出登录或清空 Cookie 后，刷新 Lazer 首页。
- **预期结果**：
  - 首页平滑回退展示全球热门官方公共榜单（Top 50 Global / USA 等）；
  - 无网络崩溃、无白屏，界面优雅降级。
