## 🥇 第一梯队 (P0)：核心曲库资产闭环（优先级最高）

本梯队聚焦于**解决日常使用中曲库信息不全、资产无法触达的硬伤痛点**，让用户在 Spotify 积累多年的曲库资产在 Lazer 中全面可用。

### 1.1 用户云端自建与收藏歌单列表打通 (`userPlaylists`)

- **现状痛点**：目前 Spotube 在 Lazer 左侧资料库中仅同步了「我喜欢的音乐」（Liked Songs），用户在 Spotify 中精心创建或收藏的自建歌单（如 Workout、J-Pop、Study 等）在 Lazer 中完全空白，必须手动复制 Web URL 搜索才能打开。
- **协议依据 (`SpotAPI/library.py` & `operations.py`)**：
  Spotify 内部通过 Pathfinder GraphQL 的 `fetchLibrary` 端点批量拉取用户的 Library 实体：
  ```graphql
  # 操作名: fetchLibrary
  query fetchLibrary($offset: Int, $limit: Int) {
    me {
      libraryV3(offset: $offset, limit: $limit) {
        items {
          item {
            data {
              ... on Playlist {
                uri
                name
                images { items { sources { url } } }
                ownerV2 { data { name } }
                tracks { totalCount }
              }
            }
          }
        }
      }
    }
  }
  ```
- **落地改造**：
  1. 声明 `capabilities = [..., "userPlaylists"]`；
  2. 在 `spotube/services/spotify.lua` 中封装 `fetch_user_playlists(offset, limit)`；
  3. 实现 Lazer 的 `userPlaylists` 契约，直接将用户的自建与收藏歌单呈现在左侧资料库中。

---

### 1.2 歌手详情主页与作品全集 (`artistDetails` / `artistSongs`)

- **现状痛点**：在正在播放页、专辑曲目列表点击艺人名字时，由于缺少歌手契约，无法跳转至歌手专属主页，无法进一步探索该艺人的其他代表作。
- **协议依据 (`SpotAPI/operations.py`)**：
  Spotify 提供了 `queryArtistOverview` GraphQL 操作：
  - 获取艺人高清写真与月度听众数（Monthly Listeners）；
  - 获取艺人 Top 5 热门代表歌曲（Top Tracks）；
  - 获取艺人发行唱片（Albums）与单曲/EP（Singles & EPs）。
- **落地改造**：
  1. 声明 `capabilities = [..., "artistDetails", "artistSongs"]`；
  2. 实现 `artistDetails(args)` 与 `artistSongs(args)` 契约，自动解析 Top Tracks 与专辑展架，实现完整的歌手主页导航。

---

### 1.3 匹配音频流 2 小时二级缓存 (`streamCache`)

- **现状痛点**：当前每次切歌都需要重新调用 YouTube InnerTube 接口并运行置信度比对，造成单曲启动有 300~800ms 的网络寻址等待；在歌单中“上一曲/下一曲”反复切换时体验卡顿且浪费带宽。
- **落地改造**：
  1. 在 `spotube/core/store.lua` 中建立基于 `track_id` 的带 TTL（2 小时）本地持久化映射；
  2. 二次播放同一单曲时优先命中缓存直链，**实现 0 延迟秒开播放**。

## 🥈 第二梯队 (P1)：视听质感与算法跃升（核心竞争力）

本梯队聚焦于**大幅提升听觉品质与歌词命中率**，引入 Spotube 官方的核心换源机制与 Spotify 算法。

### 2.1 双轨歌词引擎：Spotify Color Lyrics 官方原生歌词 + LRCLIB 自动回退

- **现状痛点**：当前仅依赖 LRCLIB，虽然免鉴权且干净，但在许多最新发行、小众外文流行歌曲中，LRCLIB 经常出现“暂无歌词”。
- **协议依据 (`SpotAPI/lyrics.py` & `_lyrics_sync.py`)**：
  只要拥有 `sp_dc` 登录态，Spotify 官方在 `spclient` 端点直接提供毫秒级时间戳歌词（Color Lyrics）：
  ```http
  GET https://spclient.wg.spotify.com/color-lyrics/v2/track/{track_id}?format=json&market=from_token
  Authorization: Bearer <access_token>
  ```
  返回结构包含逐行（Line-level）乃至逐字（Syllable-level）精确时间戳 `startTimeMs` 与歌词内容。
- **落地架构**：
  1. **首选官方**：检测到用户已登录时，优先调用 `spclient.wg.spotify.com/color-lyrics/v2/track/{track_id}` 拉取官方原生歌词；
  2. **智能回退**：若未登录或官方端点返回 404/无歌词，平滑无感降级至 LRCLIB；
  3. **收益**：实现全曲库 99.5% 以上的超高歌词命中率，且完美适配 Lazer 流光高亮背景。

---

### 2.2 备选音轨手动换源 (`Alternative Tracks Switcher`)

- **参考依据 (`team-spotube/spotube`)**：
  在 Spotube 官方 Kotlin 架构中，核心组件 `AlternativeTracksRepository` 与 `AlternativeTrackContent` 是其精髓设计：
  当置信度算法偶尔把录音室版本匹配成 Live 现场版、翻唱或伴奏版时，允许用户主动纠正并记忆。
- **落地架构**：
  1. 利用 Lazer 的 `player_menu` 扩展正在播放页的操作菜单，新增【换源 / 备选音轨】项；
  2. 触发时，返回置信度匹配器搜索到的前 5 条 YouTube 备选音轨列表（展示视频标题、时长偏差、频道名称与相似度得分）；
  3. 用户点击某一条目后，即时切换播放流，并在本地持久化绑定 `track_id -> selected_youtube_id`，彻底解决“错配”顽疾。

---

### 2.3 Spotify 算法推荐与单曲电台 (`recommendations` / `radio`)

- **参考依据 (`SpotAPI/queries.py` & Spotify Web API)**：
  Spotify 最为人称道的王牌能力就是其音频特征推荐引擎。通过 `/v1/recommendations?seed_tracks={track_id}`，可以根据单曲的 BPM、音色、调性推荐源源不断的相似单曲。
- **落地架构**：
  1. 声明 `capabilities = [..., "recommendations", "radio"]`；
  2. 实现单曲电台契约，点击单曲菜单的【开启心动模式 / 相似单曲电台】即刻生成沉浸式无限流动推荐。

## 🥉 第三梯队 (P2)：主页个性化与深度资产交互

本梯队聚焦于**增强主页的千人千面个性化推荐，并打通曲目双向管理**。

### 3.1 登录用户个性化主页展架 (`Daily Mix` / `Discover Weekly` / `Release Radar`)
- **现状**：目前主页展示固定的全球/美区/日区 Top 50 官方榜单。
- **规划**：通过 Spotify `views` 接口，在已登录状态下动态捕获官方为该用户量身定制的：
  - **每日混音（Daily Mix 1~6）**
  - **每周发现（Discover Weekly）**
  - **新歌雷达（Release Radar）**
  使主页真正成为用户的个性化专属音乐广场。

### 3.2 歌单管理：将单曲添加到 Spotify 云端歌单 (`editPlaylists`)
- **规划**：声明 `editPlaylists` 契约，支持在 Lazer 菜单中将正在播放的歌曲一键加入用户自建的 Spotify 云端歌单，桌面端与手机 Spotify App 即时同步。

### 3.3 音频码率与音质设置项 (`host.add_setting`)
- **规划**：在 Lazer 设置中心注册音质切换选项：
  - `标准音质 (128kbps AAC)`
  - `高清音质 (160kbps Opus)`
  - `节省流量模式`

## 🎖️ 第四梯队 (P3)：极客生态与互联体验

### 4.1 听歌历史上报与年度总结参与 (`scrobble`)
- **规划**：在歌曲播放进度超过 50% 时向 Spotify 内部 API 发送播放心跳，将 Lazer 的播放行为计入个人 Spotify 真实听歌历史，参与每年年底的 Spotify Wrapped 年度歌单大盘点。

### 4.2 Jam 一起听协议探索 (`listenTogether`)
- **规划**：基于 WebSocket 协议，对标 Spotube 官方的 `JamRoomService`，支持多端与好友远程同步播放进度与歌单队列。
